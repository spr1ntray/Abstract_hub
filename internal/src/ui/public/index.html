ВХОД В АККАУНТ

Вход через Abstract

У Abstract Global Wallet нет экспортируемого приватного ключа. Приложение отдельно получает ограниченные права, не запрашивая основной ключ и не сохраняя JWT вручную.

  1. Откройте Аккаунты и нажмите Подключить Abstract в нужной строке.
  2. По ссылке Abstract подтвердите единичный доступ и вернитесь в приложение.
  3. После статуса «Автоматизация разрешена» Gigaverse, Discover и транзакционные модули используют это подключение автоматически. Для Cambria хаб отдельно покажет одноразовую ссылку в выбранный браузер.

Не присылайте в чат, HAR или видео данные сессии Abstract. Разрешение хранится локально в зашифрованном хранилище приложения.

Подключение выполняется отдельно для каждого аккаунта и отдельно на каждом компьютере. Повторный вход потребуется только после отзыва или истечения разрешения. Основной ключ AGW приложению не передаётся.

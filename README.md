# Abstract Hub

Локальный desktop-хаб для ежедневных действий в экосистеме Abstract на macOS и Windows.
Gigaverse — первый полностью автоматизированный игровой модуль.

## Скачать

- [macOS — Universal DMG](https://github.com/spr1ntray/Abstract_hub/releases/download/v0.1.52/Abstract.Hub-0.1.52-macOS-universal.dmg)
- [Windows — x64 Installer](https://github.com/spr1ntray/Abstract_hub/releases/download/v0.1.52/Abstract.Hub-0.1.52-Windows-x64.exe)

Для обычного запуска клонировать репозиторий и устанавливать Node.js не нужно. Все готовые версии
лежат на странице [GitHub Releases](https://github.com/spr1ntray/Abstract_hub/releases/latest).

## Что умеет

- Подключает несколько Abstract-аккаунтов без приватных ключей и ручного ввода JWT.
- Автоматически поддерживает ежедневный стрик Abstract Discover без отдельной настройки.
- Парсит еженедельные начисления Abstract XP, хранит историю и отмечает новые начисления.
- Подхватывает активные flash-бейджи из data-pack и показывает их в постоянном разделе `Бейджи`.
- Сначала разбивает доступные кувшины и забирает награды из сундуков, затем запускает данжи.
- Крафтит, ремонтирует и утилизирует перчатки.
- Прокачивает боевые скиллы по заданной стратегии.
- Показывает инвентарь с изображениями и позволяет выставлять предметы на маркет.
- Никогда автоматически не продаёт Wood и Stone.
- Открывает ежедневные миссии, инвентарь и Store Tollan в браузере.
- Запускает Practice Tollan в официальном клиенте и отслеживает серверное подтверждение награды.
- Поддерживает отдельный прокси и выбор данжа для каждого аккаунта.
- Позволяет запускать один или несколько выбранных аккаунтов и выполнять Gigaverse и Tollan
  параллельно.

## Как работает

Abstract подключается через одноразовую ссылку в обычном браузере. При первом подключении нужно
разрешить `Sign message` и `Send transaction`. После этого приложение само получает и обновляет
игровую сессию Gigaverse, выполняет разрешённые транзакции и поддерживает Discover-стрик.

Tollan работает через AdsPower Local API. В хабе хранится один общий API key, а к каждому
Abstract-аккаунту привязывается отдельный профиль AdsPower. Хаб сохраняет его внутренний ID,
запускает нужный профиль и управляет официальными страницами через локальный CDP-интерфейс.
Cookies, fingerprint, расширения и прокси остаются внутри AdsPower; отдельные localhost-входы для
Tollan не используются. Переходы по разделам ничего не запускают: работа начинается только по явной
кнопке, а очередь добавляет случайные паузы между аккаунтами и действиями.

Abstract начисляет XP пакетами раз в неделю и сам отражает их в профиле Rewards. Отдельной
транзакции claim для XP нет, поэтому хаб проверяет начисления, но не имитирует несуществующий клейм.

Аккаунты и настройки хранятся локально в зашифрованном виде. Мастер-пароль после успешного входа
сохраняется системным хранилищем паролей macOS или Windows, чтобы фоновые задачи продолжали
работать после следующего запуска приложения.

## Запуск готового приложения

### macOS

1. Открой скачанный файл `Abstract Hub-*-macOS-universal.dmg`.
2. Перетащи приложение в `Applications` и запусти его.
3. Если macOS блокирует запуск, нажми по приложению правой кнопкой и выбери `Открыть`.

### Windows

1. Запусти скачанный файл `Abstract Hub-*-Windows-x64.exe`.
2. Пройди установку и открой `Abstract Hub`.

### Первый вход

1. Запусти AdsPower и включи Local API в `Automation` → `API`.
2. Во вкладке `Аккаунты` укажи общий API key и нажми `Проверить и загрузить профили`.
3. Добавь строку аккаунта, выбери профиль AdsPower и нажми `Подключить Abstract`.
4. Скопируй или открой предложенную ссылку в браузере с нужным Abstract-аккаунтом.
5. Укажи прокси и данж, затем задай мастер-пароль и сохрани аккаунты.
6. Один раз войди в Tollan внутри соответствующего AdsPower-профиля.
7. Перейди в нужный раздел хаба и запусти автоматизацию.

Один AdsPower-профиль нельзя привязать к двум аккаунтам. AdsPower должен быть запущен во время
работы Tollan; API key и соответствия профилей сохраняются в зашифрованном хранилище.

Расширения, ручная работа с папками и копирование JWT не нужны.
Интерфейс работает в отдельном окне `Abstract Hub`; локальный web-сервер используется только
внутри desktop-приложения и не является способом запуска для пользователя.

## Обновления

- `Data-pack` обновляет проверенные адреса API, игровые ID и маршруты модулей прямо в хабе.
- `Core` обновляет сам движок. Новый установщик использует прежнее зашифрованное хранилище:
  повторно подключать аккаунты не нужно.
- Предыдущий data-pack можно восстановить одной кнопкой во вкладке `Обновления`.

## Диагностика

Семь раз нажми по номеру версии в левом нижнем углу, чтобы открыть скрытый раздел `Диагностика`.
Включи запись и повтори проблемное действие. Хаб сохранит события frontend, локального API, Tollan и
Electron; при сбое Tollan также сохранится снимок официального игрового окна.
Кнопка `Открыть папку` показывает готовые JSONL-логи и снимки.

Мастер-пароль, приватные ключи, токены, cookies, подписи и секреты одноразовых ссылок автоматически
маскируются. Режим остаётся включённым после перезапуска, пока его не выключат вручную.

## Запуск из исходников

Требования: Node.js 22.12 или новее и pnpm.

```bash
pnpm install
pnpm desktop
```

Сборка установщиков:

```bash
pnpm dist:mac
pnpm dist:win
```

`dist:mac` запускается на macOS, `dist:win` — на Windows.

## Безопасность

- Не передавай другим людям мастер-пароль или данные подтверждения Abstract.
- Пользовательские данные не входят в исходный код и установщики.
- Чистая копия не содержит аккаунтов, прокси, игровых сессий, логов или базы состояния.
